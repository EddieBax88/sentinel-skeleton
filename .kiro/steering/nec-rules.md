# NEC Content Rules

These rules apply to all generated text, UI copy, documentation, and code comments.

1. **Never quote NEC text.** Paraphrase the rule and cite the article, section, or table (e.g., "per 310.16" or "see Table 314.16(A)").
2. **Every NEC citation AND every value taken from an NEC table (box fill volumes, conductor areas, raceway areas, motor full-load currents, ampacities, standard breaker sizes) is unverified until the founder confirms it against the founder's NFPA 2026 source.** Store every table value in a data file with a source field naming the table and a `nfpa_checked: false` flag. Never hardcode table values inside calculator logic.
3. **Never say "exact page."**
4. **Never use the word "Codeology."**
5. **Never promise passing an exam.** Do not imply the app guarantees a passing score or outcome.
6. **No gendered language.** Official credential names (e.g., Journeyman Electrician) are acceptable; avoid gendered pronouns or other gendered terms.
7. **No invented testimonials.** Do not fabricate quotes, reviews, or endorsements from users or instructors.
8. **Never use the names Code Compass or NEC Co-Pilot anywhere.**
9. **Never name a method by a step count.** Do not use "5-Step", "five steps", or "3 steps" (or any similar count) in method names, UI copy, drill data, or docs. The two methods are named Index Keyword Lookup and Table of Contents Lookup.
